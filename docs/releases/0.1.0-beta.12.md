# Meshy Torrent 0.1.0-beta.12

Internal observability release. No user-facing changes.

## Changes

- Added operational metrics infrastructure: event-loop utilization and latency
  percentiles (p50/p95/p99), disk usage, download state counts, and diagnostic
  counters are now collected and exposed alongside the existing IPC call counters.
- Added `metricHistogram` for fixed-bucket latency histograms covering IPC
  operations and engine events.
- Added operation context propagation via `AsyncLocalStorage`: every IPC call
  now carries a correlation ID and optional parent trace ID through the entire
  async call chain, eliminating the previous per-call random-bytes approach.
- Added `tracing.ts`: span-based operation tracing that writes structured
  start/end log entries with duration and success fields without an external
  collector.
- Replaced the free-form log-context formatter with structured log records:
  every log call now includes `schemaVersion: 1`, a stable `event` field, and
  the active operation context IDs, making logs machine-parseable.
- Extended `logRedaction` with `serializeLogError` for consistent, redacted
  error serialization used across IPC error paths and metrics.
- `torrent:error` push events now include a `traceContext` field so the
  renderer can correlate errors with the originating IPC operation.
- Updated `useDownloads` to forward `traceContext` from error events to the
  download store.

## Installation and update

Use Check for updates in the app, or download the Windows x64 installer from this
release. The installer, blockmap, update manifest, and SHA-256 checksums are
included.

## Known issues

This beta is distributed without an Authenticode signature. Windows may show an
unknown publisher warning during installation. Local TCP transfer and isolated
renderer/preload checks do not replace clean-machine installation testing.
