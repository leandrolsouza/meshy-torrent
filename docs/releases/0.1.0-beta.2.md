# Meshy 0.1.0-beta.2

Esta versão corrige o feedback da ação de remover torrents: se a solicitação de
remoção falhar, a interface agora apresenta uma mensagem de erro em vez de deixar
a falha silenciosa.

## Instalação e atualização

Baixe `Meshy-0.1.0-beta.2-win-x64-setup.exe` e `SHA256SUMS` desta versão em
[Releases](https://github.com/leandrolsouza/meshy-torrent/releases), confira o hash
e execute o instalador por usuário. Esta beta não possui assinatura Authenticode e
as atualizações continuam manuais.

O release também inclui o blockmap e `latest.yml`; esses arquivos não ativam o
atualizador integrado enquanto o pacote não for assinado.
