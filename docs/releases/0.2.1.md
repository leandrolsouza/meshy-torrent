# Meshy Torrent 0.2.1

This release adds explicit detection and rejection of BitTorrent v2-only content,
so incompatible entries receive a clear error message instead of a cryptic failure.
It also fixes a notification bug introduced in 0.1.0-beta.14 where downloads
restored from a previous session would trigger a completion notification on startup.

## Changes

- **V2-only detection.** The app now identifies BitTorrent v2-only magnets
  (links carrying only a `btmh` identity, no `btih`) and v2-only torrent files
  (files whose `info` dictionary contains `meta version = 2` without the v1
  `pieces` field). Both are rejected before a temporary WebTorrent client is
  created, with a user-visible error in English and Portuguese. Hybrid torrents
  that include v1 metadata continue to work.
- **Notification fix.** On startup, downloads already present in the restored
  session are no longer treated as newly completed. Only transitions that happen
  while the app is running trigger the completion notification.
- **Engine compatibility notes.** Added `docs/ENGINE_COMPATIBILITY.md` with a
  matrix of torrent format support under WebTorrent 3 and parse-torrent 11, plus
  findings from the TECH-01 investigation of file priority, per-torrent limits,
  and metadata resolution.
- **QA scripts.** Added scripts for bandwidth transfer, engine file-selection
  exercise, metadata capability smoke test, and torrent format compatibility
  fixtures.
- **README update.** Version badge and manifest reference updated to 0.2.1.

## Installation and update

Use Check for updates in the app, or download the Windows x64 installer from
this release. The installer, blockmap, update manifest, and SHA-256 checksums
are included.

## Known issues

This release is distributed without an Authenticode signature. Windows may show
an unknown publisher warning during installation.

BitTorrent v2-only content is not supported. Use a v1 or hybrid torrent instead.
