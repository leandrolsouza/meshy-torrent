# Meshy Torrent 0.2.0

Improved magnet URI handling: the app now accepts both hexadecimal and Base32
btih identities, normalizes the URI before passing it to the engine, and detects
conflicting hashes in the same link.

## Changes

- Added `normalizeMagnetUri` to the shared validation layer. It accepts v1
  info-hash identities in either 40-character lowercase hex or 32-character
  Base32 format, decodes percent-encoded characters in parameter values,
  converts Base32 to hex, and returns the canonical URI alongside the extracted
  info hash. Links with multiple `xt` parameters that carry different hashes are
  rejected.
- The torrent engine, download manager, and torrent preparation now use
  `normalizeMagnetUri` instead of a plain regex match. The engine receives the
  normalized URI with the hash in lowercase hex, and duplicate detection runs
  before the link is forwarded to WebTorrent.
- Updated error messages in English and Portuguese to describe the accepted
  formats (hexadecimal or Base32 btih identity) instead of repeating the old
  fixed-prefix requirement.

## Installation and update

Use Check for updates in the app, or download the Windows x64 installer from
this release. The installer, blockmap, update manifest, and SHA-256 checksums
are included.

## Known issues

This release is distributed without an Authenticode signature. Windows may show
an unknown publisher warning during installation.
