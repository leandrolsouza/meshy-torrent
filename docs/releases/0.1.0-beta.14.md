# Meshy Torrent 0.1.0-beta.14

Observability and reliability improvements for the main process. No new
user-facing features.

## Changes

- Added per-process resource monitoring: CPU usage, memory (working set and
  peak), and idle wake-ups are now collected from Electron's process metrics
  on every operational sample and stored alongside the existing download-state
  counters.
- Added GPU status tracking: hardware-acceleration state and Chromium GPU
  feature flags are recorded once the GPU process is ready and included in
  each metrics snapshot.
- Added a `--disable-hardware-acceleration` CLI flag and a
  `MESHY_DISABLE_HARDWARE_ACCELERATION=1` environment variable to opt out of
  GPU rendering before the app window is created.
- Refactored crash-state persistence into a single `persistCrashState()`
  function that deduplicates concurrent flush calls so the session and metrics
  are written exactly once per crash event.
- Fixed notification click handlers to resolve the main window dynamically
  via a `getMainWindow` callback instead of capturing a fixed reference at
  construction time.

## Installation and update

Use Check for updates in the app, or download the Windows x64 installer from
this release. The installer, blockmap, update manifest, and SHA-256 checksums
are included.

## Known issues

This beta is distributed without an Authenticode signature. Windows may show
an unknown publisher warning during installation. Local TCP transfer and
isolated renderer/preload checks do not replace clean-machine installation
testing.
