# Meshy Torrent 0.1.0-beta.8

Internal maintenance release. No user-visible changes.

## Changes

- Split the main-process IPC handler into eight domain-specific modules under
  `main/ipc/` (torrent, batch, bandwidth, queue, settings, tracker, application,
  and shared context), reducing the size of the original `ipcHandler.ts` by over
  1 300 lines.
- Extracted session-persistence logic from `DownloadManager` into
  `main/downloadSession.ts`, exposing `DownloadSessionRepository`,
  `validatePersistedDownloadItem`, and `serializePersistedDownloadItem` as
  individually testable units.
- Introduced narrow engine-port interfaces in `main/enginePorts.ts`
  (`DownloadManagerEngine`, `TorrentIpcEngine`, `BandwidthControlEngine`,
  `DownloadDiagnosticsEngine`) so each service depends only on the operations it
  actually uses, with no behaviour changes at runtime.

## Installation and update

Use Check for updates in the app, or download the Windows x64 installer from this
release. The installer, blockmap, update manifest, and SHA-256 checksums are
included.

## Known issues

This beta is distributed without an Authenticode signature. Windows may show an
unknown publisher warning during installation. Local TCP transfer and isolated
renderer/preload checks do not replace clean-machine installation testing.
