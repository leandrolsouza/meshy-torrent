# Meshy Torrent 0.1.0-beta.13

Performance and reliability improvements for session persistence, tab polling,
and download state updates. Includes test infrastructure updates for the async
folder-validation introduced in 0.1.0-beta.12.

## Changes

- Added async protected store writer (`asyncProtectedStore`) that holds the
  session in memory and persists encrypted snapshots atomically via a
  write-to-temp-then-rename pattern, eliminating the window where a crash could
  leave a partial session file.
- Session persistence in `DownloadManager` is now debounced: rapid state changes
  coalesce into a single write, reducing I/O during active downloads. A new
  `flushSessionPersistence()` method ensures the latest snapshot is written
  before the app exits.
- Destination folder validation is now fully async (`stat` + `access` instead of
  the blocking `existsSync` / `accessSync`), preventing event-loop stalls when
  checking network or slow drives.
- Fixed `usePolling` allowing concurrent in-flight calls: a guard now prevents
  a new tick from starting while the previous one is still awaited, avoiding
  overlapping IPC calls on slow responses.
- Peers and Pieces tabs now receive an `isActive` prop and stop polling when
  the panel is collapsed or a different tab is selected.
- Download store updates use a shallow `itemsEqual` check: items that arrive
  unchanged from the progress push no longer trigger re-renders.

## Installation and update

Use Check for updates in the app, or download the Windows x64 installer from this
release. The installer, blockmap, update manifest, and SHA-256 checksums are
included.

## Known issues

This beta is distributed without an Authenticode signature. Windows may show an
unknown publisher warning during installation. Local TCP transfer and isolated
renderer/preload checks do not replace clean-machine installation testing.
