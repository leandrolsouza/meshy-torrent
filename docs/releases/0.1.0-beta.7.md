# Meshy Torrent 0.1.0-beta.7

Completed torrents can now keep sharing data with other peers through automatic
seeding.

## Changes

- Added a Seeding section under Settings → Network, with an enable switch and a
  concurrent seeder limit from 1 to 20 (default: 2).
- Added Seeding status, upload speed, and Stop seeding / Resume seeding actions.
- Added a FIFO seed queue and session restoration that preserve per-torrent choices.
  Seeders use separate slots from downloads and respect the global upload limit.
- Fixed restoring complete torrents while paused and reporting verified file sizes
  at exact piece boundaries.
- Updated the app and installer display name to Meshy Torrent.

## Installation and update

Use Check for updates in the app, or download the Windows x64 installer from this
release. The installer, blockmap, update manifest, and SHA-256 checksums are included.

## Known issues

This beta is distributed without an Authenticode signature. Windows may show an
unknown publisher warning during installation. Local TCP transfer and isolated
renderer/preload checks do not replace clean-machine installation testing.
