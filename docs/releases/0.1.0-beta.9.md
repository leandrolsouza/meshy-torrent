# Meshy Torrent 0.1.0-beta.9

Bug-fix release. No new features.

## Changes

- Fixed disk-space query blocking when a previously-used download folder becomes
  inaccessible: errors on individual volumes are now isolated, so the check
  continues for all reachable destinations.
- Fixed a window where a partial session snapshot could be written while downloads
  were still being restored on startup; the previous state is now preserved if
  restoration does not complete cleanly.
- Fixed session persistence swallowing errors silently after an engine failure;
  persistence failures during error handling are now logged and do not interrupt
  the download queue.
- Fixed torrent preparation hanging indefinitely when the metadata client's
  `destroy` callback never fires; a 5-second timeout now rejects the operation
  and frees the slot.
- Fixed the error boundary showing untranslated strings when the crash occurred
  inside the locale provider tree; the fallback UI now supplies its own
  `IntlProvider` using the active locale.

## Installation and update

Use Check for updates in the app, or download the Windows x64 installer from this
release. The installer, blockmap, update manifest, and SHA-256 checksums are
included.

## Known issues

This beta is distributed without an Authenticode signature. Windows may show an
unknown publisher warning during installation. Local TCP transfer and isolated
renderer/preload checks do not replace clean-machine installation testing.
