# Meshy Torrent 0.1.0-beta.6

Fixed removal actions for completed downloads. The Remove action in a download's
menu and Clear completed now open their confirmation dialog when clicked.

Removal also waits for the completed torrent's peer discovery cleanup, so the
download can be removed after it finishes.

## Installation and update

Meshy Torrent beta.5 users can check for this update in the app. The Windows x64 installer
and SHA-256 checksums are also available on the
[GitHub Releases page](https://github.com/leandrolsouza/meshy-torrent/releases).

## Known issues

This beta is distributed without an Authenticode signature. Windows may show an
unknown publisher warning during installation.
