# Meshy 0.1.0-beta.5

As atualizações automáticas funcionam também nos instaladores Windows x64 sem
certificado. O app consulta somente o feed HTTPS do repositório oficial e confere o
SHA-512 do instalador publicado. Sem assinatura Authenticode, a identidade do
editor não é verificada.

## Atualizar da beta.2

A beta.2 ainda bloqueia o updater. Instale esta versão manualmente uma vez; depois
disso, o Meshy poderá baixar futuras versões beta.

Baixe `Meshy-0.1.0-beta.5-win-x64-setup.exe` e `SHA256SUMS` desta versão em
[Releases](https://github.com/leandrolsouza/meshy-torrent/releases), confira o hash
e execute o instalador por usuário. O Windows pode mostrar um aviso de editor
desconhecido, pois o instalador não possui assinatura Authenticode.
